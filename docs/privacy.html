Mathlete Daily Coach — Privacy Policy

Last updated: October 15, 2026

Mathlete Daily Coach is a Chrome extension for daily math-competition practice. This policy explains what it stores and what it does not do.

What the extension stores

All of the following is saved only on your computer, in Chrome's local extension storage:

  • The first name you enter for your child
  • A salted, one-way hash of the parent PIN (the PIN itself is never stored)
  • Practice history: which topics were practiced, answers given, whether they were correct, time taken, and the text of recently missed questions
  • Streaks, points, badges and settings (questions per day, unlock options, allowed websites)

What the extension does not do

  • It does not send any data to the developer or to anyone else. It makes no network requests.
  • It has no accounts, analytics, advertising or tracking.
  • It does not read, record or transmit the content of web pages you visit.
  • It does not sell or share data, because it never collects any.

How the permissions are used

  • Website access and network rules (declarativeNetRequest, all-sites host access): to block websites, search engines and answer sites while the browser is locked, and to redirect blocked pages to the extension's own "locked" page. Blocking happens inside Chrome; no browsing data leaves the computer.
  • Tabs: to keep the practice tab in focus while locked and to switch tabs that are not allowed to the extension's "locked" page.
  • Storage: to save the practice history and settings listed above on your computer.
  • Alarms: to lock the browser again when an unlock period ends.

Deleting your data

Use Parent → Lock & settings → Reset all progress, or remove the extension from Chrome. Removing it deletes everything it stored.

Children

The extension is designed to be set up by a parent for a child. It does not collect personal information from children or anyone else; the only personal detail (a first name) stays on the device.
